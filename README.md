### O Projeto 🧪

O mocape é uma aplicação Full Stack onde consigo comprovar habilidades técnicas, expor meus criativos e apresentar soluções práticas. O objetivo é mostrar como a IA Generativa e Automação podem ser usadas para resolver problemas reais de negócios, otimizar processos e melhorar a experiência do usuário no dia a dia.
